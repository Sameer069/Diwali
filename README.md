# 🪔 Interactive Diwali Celebration Website

An immersive, interactive 3D Diwali celebration experience built with React, featuring advanced animations, interactive elements, and playful surprises.

## ✨ Features

### 🎬 Cinematic Intro Animation
- Dark screen with appearing stars
- Animated matchstick lighting a diya
- Glowing light effects that illuminate the entire screen
- Massive fireworks launch on button click

### 🪔 Interactive Diya Experience
- Multiple beautifully designed 3D-style diyas
- Realistic animated flames
- Click to light each diya with golden particle explosions
- Funny Diwali messages
- "Light All Diyas" sequential animation

### 🎆 Interactive Fireworks Game
- Click anywhere to launch custom fireworks
- Canvas-based particle effects
- Fireworks counter
- "GO CRAZY" mode with automatic fireworks storm
- Flying rocket animations

### 😂 Funny Friendship Challenge
- 5 playful quiz questions
- Animated card reveals
- Funny reactions and emojis
- Friendship compatibility meter

### 🎁 Surprise Gift Box Section
- 6 interactive 3D gift boxes
- Spring animation lid opening
- Golden light bursts and confetti
- Personalized friendship messages

### ❤️ Best Friend Mode
- Toggle-able special mode
- Animated friendship meter filling to 100%
- Floating friendship badges
- Virtual friendship certificate
- Rotating friendship messages

### 🛤️ Memory Lane Timeline
- 6 flip-able memory cards
- Beautiful timeline layout
- Interactive card reveals
- Customizable memories

### 🎊 Grand Finale Celebration
- Full-screen continuous fireworks
- Multiple animated diyas
- Floating golden particles
- Beautiful final message
- Three action buttons:
  - Celebrate Again
  - Reveal One Last Surprise
  - Send This Wish

## 🛠️ Technology Stack

- **React 18** - UI framework
- **Vite** - Build tool
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - React animations
- **GSAP** - Complex animation timelines
- **Canvas API** - Fireworks and particles
- **Canvas Confetti** - Celebration effects
- **Lucide React** - Beautiful icons

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎭 Customization

You can easily customize:

1. **Messages**: Edit funny messages in each component
2. **Colors**: Modify the Tailwind config for different color schemes
3. **Memories**: Update the memory cards with your own stories
4. **Gift Messages**: Change surprise messages in GiftBoxSection
5. **Quiz Questions**: Add or modify questions in FriendshipQuiz
